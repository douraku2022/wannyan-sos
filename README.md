# 🐕🐈 ワンニャンSOS熊本

犬猫のお世話に必要な「物資」を通じて、お困りの方と応援したい方を双方向でつなぐ伝言板アプリです。

できるひとが、できるときに、できることを。

**運営：** どうらくいちば犬猫支援プロジェクト
**現在のステータス：** 実証テスト運用中（2026年8月〜）

---

## これは何か

被災地・保護活動の現場では、「あの避難所には物資が何度も届くのに、こちらには全く届かない」というような、支援の偏りが起きがちです。これは、困っている側が声を上げる手段を持っていないことが大きな原因だと考えています。

このアプリは、その「声を上げる手段（＝救難信号）」を、誰でも・スマホひとつで・ニックネームだけで持てるようにすることを目指しています。

- 🆘 **不足している**：物資が足りない施設・個人が、必要な物と量を投稿
- ✳️ **支援できる**：物資を渡せる人が、渡せる物を投稿
- 双方向のマッチングを、個別チャットで調整

## 開発の背景

2026年8月28日に開発を開始し、約1週間で主要機能を実装しました。開発者はプログラミング未経験からのスタートです。

## 主な機能

- 電話番号＋暗証番号によるシンプルな会員登録・ログイン
- QRコードからその場で登録できる導線（現場のボランティアが配布）
- ニックネーム制（本名・住所は非公開、運営のみ管理用に把握）
- 物資の過不足を投稿するマッチング掲示板
- 投稿者ごとに分離された個別チャット
- 管理者による運営情報・お知らせの投稿機能
- 通報対応のための管理者権限（投稿の削除・非表示化）

## セキュリティについて

個人情報保護を最優先に設計しています。

- 個別チャットは1対1で完全に分離（RLSによりDB側で保護）
- 本名・住所・電話番号は非公開。画面に出るのはニックネームのみ
- 金銭のやり取りが発生しない仕組み（物資支援限定）
- 投稿の更新はDB側で自動的に記録され、こっそりとした書き換えができない設計
- ニックネーム等の自由入力欄からのコード注入（XSS）を防止
- なりすまし防止のため、お知らせ・運営情報は認証された管理者のみ投稿可能

## 今後の展望

この仕組みや理念に共感してくださる公的機関・自治体等の公的な主体へ、ゆくゆく管理・運営を引き継いでいただける未来を目指してデザインしています。

### エリア設計を「災害救助法適用エリア」に接続する構想

現在のエリア一覧は、熊本県内の市郡名を手作業で登録した簡易的なものです。これを「災害救助法適用エリア」という制度上の単位に接続できれば、以下が可能になると考えています。

- エリア別・緊急度別の投稿集計が、そのまま行政の使う言葉・単位で読める形になる
- 犬猫の物資支援に限らず、生活再建・水・食料・避難所運営など、あらゆる「困りごとの信号」を同じ仕組み（投稿→集計→可視化）で拾える、汎用の災害SOSインフラへと発展させられる
- 被災地へQRコードを一斉配布し、現場から直接「救難信号」を上げてもらう動線を、動物支援に限らず広げられる

これは、どうらくいちば規模のボランティア団体が実装・運用しきれる規模の話ではなく、**本来は行政・自治体が担うべき動線**だと考えています。この構想自体を、いつか公的機関に託せる形で残しておきたく、ここに記しておきます。
